1. [Browser]: User types note and submits form
2. [Browser]: JS event handler intercepts submit event
   - Prevents default POST/reload
   - Appends new note to local array and re-renders list immediately
3. [Browser -> Server]: HTTP POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
   - Headers: Content-Type: application/json
   - Payload: {"content": "Your note text", "date": "2026-10-17"}
4. [Server]: Saves new note payload to database
5. [Server -> Browser]: HTTP 201 Created response
6. [Browser]: Stays on current DOM view (no redirect or page refresh)
