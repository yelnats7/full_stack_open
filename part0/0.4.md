1. [Browser -> Server]: HTTP POST https://studies.cs.helsinki.fi/exampleapp/new_note
   - Payload: Form data with the new note content
2. [Server]: Processing POST request
   - Action: Server appends new note to internal storage/database
   - Response: HTTP 302 Redirect to `/exampleapp/notes`
3. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/notes
   - Response: HTML document
4. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/main.css
   - Response: Stylesheet (main.css)
5. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/main.js
   - Response: JavaScript file (main.js)
6. [Browser]: Executes main.js, triggering data fetch
7. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/data.json
   - Response: Array of note objects in JSON format
8. [Browser]: Callback executes and dynamically updates DOM to render notes
