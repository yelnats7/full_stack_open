1. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/spa
   - Response: HTML document
2. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/main.css
   - Response: Stylesheet (main.css)
3. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/spa.js
   - Response: JavaScript file (spa.js)
4. [Browser]: Executes spa.js, fetching raw data via AJAX/Fetch
5. [Browser -> Server]: HTTP GET https://studies.cs.helsinki.fi/exampleapp/data.json
   - Response: JSON array containing notes data
6. [Browser]: JS callback renders notes into DOM without page reload
